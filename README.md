# Future Task Manager

**Future Task Manager** é um monitor de desempenho de sistema leve em C++ e Qt 6 para Linux, inspirado no Gerenciador de Tarefas do Windows, criado pela **Future Technology Informática**.

## Instalação Rápida
- **Debian / Ubuntu / Linux Mint / Raspberry Pi OS (APT)**
- **Fedora / RHEL / Rocky Linux / openSUSE (DNF / YUM)**
- **Slackware**

*(O arquivo `README.md` completo inclui os guias de instalação detalhados para APT, DNF e Slackware, além de informações sobre o autor Paulo Roberto Jentsch e a licença GPL-3.0).*
